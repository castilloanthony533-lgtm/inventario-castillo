# Inventario Castillo — versión para iPhone

## En Windows
1. Instala Node.js LTS.
2. Abre esta carpeta en Visual Studio Code.
3. Abre Terminal > New Terminal.
4. Ejecuta:
   npm install
   npm run dev
5. Abre la dirección que muestre Vite.

## Para abrirlo en iPhone
Esta versión es una PWA. Para usarla como aplicación en iPhone debes publicar el proyecto en un hosting HTTPS (por ejemplo Vercel o Netlify). Después abre la dirección en Safari y usa **Compartir > Añadir a pantalla de inicio**.

Incluye:
- Dashboard responsivo.
- KPI del valor total del inventario.
- Gráfico de barras por categoría.
- Tabla editable.
- Alertas de stock bajo.
- 4 usuarios.
- Pantalla preparada para escaneo.
